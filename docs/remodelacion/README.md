# Remodelación de la aplicación

Carpeta para documentar los cambios por página antes de armar el plan.

**Flujo**
1. Copiar `_PLANTILLA-PAGINA.md` → `<pagina>.md` (uno por ruta).
2. Completar situación actual, problemas e historias de usuario.
3. Marcar el estado como *Listo para plan* y consolidar en `PLAN.md`.
